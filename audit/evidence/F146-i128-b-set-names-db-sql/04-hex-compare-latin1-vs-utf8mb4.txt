时间: 2026-11-08 00:26 ~ 00:29
来源: 本次会话终端原始输出摘录（两次建库执行 + HEX 比对）

--- 实验设计 ---
库 A = tmp_setnames_test : 用 mysql --default-character-set=latin1 执行（模拟容器 POSIX locale 的最坏情况）
库 B = tmp_setnames_ref  : 用 mysql --default-character-set=utf8mb4 执行
两库执行**同一批文件**、**同一份测试副本**（仅 USE / CREATE DATABASE 的库名重定向到各自临时库，
SET NAMES 行与正文逐字节未改，经 docker cp 传输保留原始字节）。
比对语句:
  SELECT permission_code, HEX(permission_name) FROM sys_permission ORDER BY id;
  SELECT role_code, HEX(role_name), HEX(description) FROM sys_role ORDER BY id;
