--- B. I211 取证：batch-analyze / batch-revoke 的 Integer->Long ClassCastException ---
admin POST /mh/visual/archive/batch-analyze  body={'ids':[99999999]}  => HTTP=200  body.code=500 (SYSTEM_ERROR)
admin POST /mh/visual/archive/batch-revoke  body={'ids':[99999999]}  => HTTP=200  body.code=500 (SYSTEM_ERROR)
admin POST /mh/visual/archive/batch-revoke  body={'ids':[9999999999]} => HTTP=200  body.code=200 (Long 绑定, 正常)
  根因: body 为 Map<String,Object> => Jackson 把小整数绑为 Integer => for (Long id : ids) 抛 ClassCastException
  容器日志: java.lang.ClassCastException: class java.lang.Integer cannot be cast to class java.lang.Long
           at com.meiyetec.service.VisualArchiveService.batchRevokeArchives(VisualArchiveService.java:313)
  前端触发: views/mh/visual.vue:1167 (batch-analyze) / :1200 (batch-revoke), ids 来自 rows.map(r => r.id) => JSON 数字 => Integer
  影响: 两个端点对所有通过权限校验的调用方恒返回 HTTP 200 + code 500 (假成功语义)
