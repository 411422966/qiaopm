# I112 — issue-register.md 中文永久损坏

## 现象
- `audit/issues/issue-register.md` 中文字符全部变成 `????`
- 显式 UTF-8 读取仍为 `????`，说明字节已被替换为 0x3F
- 英文/数字/符号保留，仅中文丢失

## 影响
- 154 KB 权威登记表中文语义全部损失
- 后续审计无法引用其中的中文描述

## 可能根因
- 某次 UTF-8 → GBK → UTF-8 的不可逆编码转换
- 与 I096（4 个 Java 源文件 UTF-8 字节损坏）可能同源
