# 美业 SaaS 消费收银会员管理系统 · 功能大全篇

> 适用行业：美容院 / 美发店 / 美甲美睫 / SPA / 会所 / 医美
> 特点：高频预约、套餐/次卡依赖、会员复购驱动、私域运营强
> 版本：v1.0 | 日期：2026-07-31

---

## 一、核心模块划分（12个标准模块 + 6个进阶模块）

### 【标准模块】

| # | 模块名称 | 优先级 | 包含功能点 |
|---|---------|-------|----------|

| M04 | 套餐/次卡/疗程卡 | P0 | 项目组合、计次管理、有效期、转让/冻结/挂起、部分核销、差价补款 |
| M05 | 储值卡 | P0 | 充值、赠送金额、消费抵扣、限时活动、余额冻结 |
| M06 | 项目/疗程管理 | P1 | 服务SOP、阶段进度、耗材绑定、护理建议、疗程报告 |
| M07 | 库存耗材 | P1 | 入库/出库、批次追溯、效期管理、预警提醒、项目自动扣减 |
| M08 | 员工管理 | P1 | 排班、考勤、绩效提成、技师等级、多维提成规则 |
| M09 | 营销工具 | P1 | 短信/微信触达、生日提醒、优惠券、积分商城、自动化触发 |

## 五、经营KPI体系

### 5.1 增长指标

| KPI | 计算方式 | 目标值 | 说明 |
|-----|---------|-------|------|
| 到店率 | 实际到店 / 预约总量 | >90% | 爽约率<10% |
| 复购率 | 30天内复购会员 / 总会员 | >40% | 行业均值25% |
| 裂变带新 | 老客推荐新客 / 总新客 | >20% | 口碑增长 |
| 预约成功率 | 成功预约 / 发起预约 | >85% | 转化漏斗 |
| 爽约率 | 爽约数 / 预约总量 | <10% | 需智能提醒 |

### 5.2 收益指标

| KPI | 计算方式 | 目标值 | 说明 |
|-----|---------|-------|------|
| 客单价 | 营业额 / 订单数 | 行业参考 | 美业均值200-500 |
| 疗程消耗率 | 已核销次数 / 购买次数 | >60% | 防止卡过期流失 |
| 毛利率 | (营业额-成本) / 营业额 | >50% | 含耗材+人力 |
| 次卡余额利用率 | 已核销金额 / 购买金额 | >70% | 卡沉寂预警 |
| 退款率 | 退款金额 / 营业额 | <3% | 异常预警 |

### 5.3 运营指标

| KPI | 计算方式 | 目标值 | 说明 |
|-----|---------|-------|------|
| 技师利用率 | 服务时长 / 工作时长 | >75% | 排班效率 |
| 房间占用率 | 占用时长 / 可用时长 | >80% | 资源效率 |
| 库存周转天数 | 平均库存 / 日消耗量 | <30天 | 避免积压 |
| 耗材差异率 | 实际消耗 / 理论消耗 | ±5% | 盘点偏差 |

### 5.4 体验指标

| KPI | 计算方式 | 目标值 | 说明 |
|-----|---------|-------|------|
| 好评率 | 5星评价 / 总评价 | >90% | 服务质量 |
| NPS | 推荐者-贬损者 | >50 | 口碑指数 |
| 回访完成率 | 实际回访 / 计划回访 | >80% | 客情维护 |
| 投诉闭环时长 | 解决时间-投诉时间 | <24h | 响应速度 |
