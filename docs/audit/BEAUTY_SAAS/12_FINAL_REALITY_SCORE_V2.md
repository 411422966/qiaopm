## 一、Reality Score 计算模型

### 1.1 评分维度与权重

根据审计原则，采用以下评分模型：

| 维度 | 权重 | 定义 |
|------|------|------|
| Feature Reality | 25% | 功能点完整度和真实性 |
| Business Logic Reality | 20% | Service/ServiceImpl 业务逻辑实现率 |
| Data Reality | 15% | 数据库表、持久化、租户隔离 |
| API Reality | 10% | Controller、Endpoint、API 完整性 |
| Runtime Reality | 10% | 运行时验证、API 实际调用 |
| Test Reality | 10% | 自动化测试覆盖率和质量 |
| E2E Reality | 10% | 端到端测试覆盖 |

### 1.2 评分公式

```
Overall Score = Σ (维度分数 × 权重)
```
