## 11. FAQ 对外答复

### 11.1 为什么需要对接数字人民币？

- 数字人民币是法定货币，商户必须受理（人民银行规定）
- 美业商户有大量小额高频交易，DCEP 实时清算，无手续费（vs. 微信/支付宝 0.6%）
- 客户隐私更强（DCEP 可控匿名），提升用户信任

### 11.2 SaaS 商户怎么收费？

- 月服务费模式（按门店/按交易额）
- 不直接对接 C 端，不涉及消费者权益纠纷
- 银行为我方结算（B2B），与 C 端数字人民币体验无关

### 11.3 资金流向？

```
消费者（数字人民币 APP）
  ↓ DCEP 实时清算
商户对公数字钱包（建行/工行/农行）
  ↓ T+1 自动到账
商户对公普通账户
```

### 11.4 退款怎么操作？

- 7 天内原路退（DCEP 钱包回 C 端数字人民币 APP）
- 7 天后走人工通道

### 11.5 风控怎么办？

- 单笔限额 5 万 / 单日 30 万（参考快捷支付限额）
- 异常交易自动告警
- T+1 对账，差错人工介入

### 11.6 数据安全 / 隐私？

- 银行侧银行级安全（加密机、PKI 体系）
- 我方只接收交易必要信息（订单号、金额），不接触客户手机号 / 身份证
- 通过 ISO 27001 / 等保三级（待认证）

### 11.7 接入周期多长？

- 聚合支付（汇元/易宝/慧呗）：2 周
- 直连建行/工行/农行：6 周
- 我们建议**两个路径并行**：聚合支付先上线兜底，同时逐家谈直连降本

### 11.8 你们和我们已有的微信 / 支付宝支付冲突吗？

- 不冲突。聚合支付服务商可以「一套接口对接微信 + 支付宝 + DCEP + 银联」全场景
- 我们的通道切换 UI 让商户自行选择支付方式

### 11.9 真实商户接入前需要我们准备什么？

- 一份商户内部对接文档（API + 收银台 UI）
- 一份商户须知（引导商户开通数字人民币对公钱包）
- 客服话术 + 常见问题应对
