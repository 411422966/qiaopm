| 角色 | PD 产品 / UI / BE 后端 / FE 前端 / QA 测试 / SRE 运维 / DBA |

## 8. 验收与发布流程

1. 每个任务由发起人填写验收清单，责任人 Review 后勾选完成。
2. Release 完成由 QA 出具集成/E2E 报告，PD 出具业务验收报告，SRE 出具发布清单。
3. 发布评审会议（PD/UI/BE/FE/QA/SRE/DBA 全员 + 业务方）签字后才允许灰度。
4. 灰度 24 小时后无异常方可全量；异常必须 30 分钟内回滚并复盘。
