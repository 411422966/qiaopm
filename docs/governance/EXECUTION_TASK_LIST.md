## 七、技术债务与风险

### 技术债务
1. **历史遗留**：部分早期功能缺少完整的单元测试
2. **数据库设计**：部分表结构需要优化以支持新功能
3. **前端组件**：部分Vue组件需要抽取为公共组件

### 风险项
1. **海外支付合规**：Stripe/Square需要商户资质审核
2. **数字人民币2.0**：依赖央行数字货币研究所API
3. **IoT设备**：需要硬件厂商配合调试
