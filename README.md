# QiaoPM - 美业智慧经营 SaaS

> 面向美容、美发、美甲、SPA、医美等美业场景的一站式智慧经营管理平台

## 产品定位

QiaoPM 是一款专为美业连锁门店设计的 SaaS 系统，涵盖预约排班、收银结算、会员管理、套餐次卡、库存耗材、员工绩效、营销工具、评价回访、数据报表、连锁总部管控等核心功能，支持多租户、多门店、跨店核销，并预留 AI 智能化和 IoT 联动能力。

## 技术架构

| 层级 | 技术栈 |

| **后端** | Spring Boot 3.1.5, Java 17, MyBatis-Plus 3.5.5, MySQL 8.0, Redis |

## 快速启动

### 前置条件

- JDK 17
- Maven 3.8+
- Node.js 18+
- MySQL 8.0（端口 3307）
- Redis 6+

### 启动后端

```bash
cd backend
mvn spring-boot:run
```

后端启动后运行在 `http://localhost:8080`，数据库连接配置位于 `src/main/resources/application.yml`。

### 启动前端

```bash
cd frontend/meiyetec-web
npm install
npm run dev
```

前端启动后运行在 `http://localhost:5173`。

### 运行 E2E 测试

```bash
cd frontend/meiyetec-web
npx playwright install chromium --with-deps
npx playwright test
```
